# Cursor set-up files

Copy into `.cursor/` at the repository root. This repository does not ship a
root `.cursor/` folder. The files here are the examples to copy.

| Asset | Path in this folder | Project path |
| --- | --- | --- |
| Skills | `skills/<name>/SKILL.md` | `.cursor/skills/<name>/SKILL.md` |
| Sub-agents | `subagents/<name>.md` | `.cursor/agents/<name>.md` |
| Hooks | `hooks/economics-hooks-example.json` | merge into `.cursor/hooks.json` |
| MCP (optional prework) | `mcp/mcp.json.example` | `.cursor/mcp.json` |

Official docs: [Cursor agents](https://cursor.com/docs), [Cursor hooks](https://cursor.com/docs/agent/hooks).
