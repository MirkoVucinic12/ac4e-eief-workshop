Open these **after** you try each exercise. Only record numbers you saw on your own machine.

What a passing check command shows: the panel is balanced, store-wave pairs are unique, the chain merge keeps the right row count, the sample counts add up, and the table matches the code. What it does **not** show: parallel trends, valid inference with two states, or a causal effect. Agents never certify those.
