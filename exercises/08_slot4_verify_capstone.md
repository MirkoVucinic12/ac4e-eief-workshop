# Exercise 08 — C11 review, C12 Goals, C13 Acceptance criteria, C14 Verification, Capstone

**When:** Fri 27 Nov 2026, 14:00–16:30 (Rome). **Example:** synthetic Card–Krueger panel, then your own work.

## A. Review the swarm (C11, 14:00–14:10)

For each returned pull request: ask `pr-reviewer` for a read-only review against `AGENTS.md` and the card, read the list of changes yourself, then merge (card → `done`) or send back (card → `ready`).

## B. Write a goal (C12, 14:10–14:25)

Rewrite one card's title as **one sentence** describing the finished state, in a form you can check. Example: "`notes/replication_audit_ck.md` exists and records GREEN, YELLOW or RED with the test output."

## C. Add acceptance criteria and relaunch (C13, 14:25–14:50)

1. Add **3 yes/no checks** to the same card. Example: "`toy_fast_food.csv` is unchanged."
2. Relaunch the agent with the goal as `/goal …` (Claude Code, Codex) or as the last line of the prompt (Cursor).
3. Judge the new pull request **only** against your 3 checks.

## D. Verification (C14, 14:50–15:50)

1. Run the check command and see it pass:

   ```bash
   python3 -m pytest examples/card-krueger-toy/tests examples/mini-economics/tests
   ```

2. On a temporary separate copy called `fault-drill`, have the agent run the table check on the planted fault `examples/card-krueger-toy/faults/drifted_table.tex` (command in [`demos/slot4_verify_capstone.md`](../demos/slot4_verify_capstone.md)). Read the error.
3. Have the agent write a corrected table to `notes/fault_drill_table.tex`, generated by the code, then rerun both checks. Do not edit tests or anything in `faults/`.
4. Fill the 3-row scorecard in [`notes/verification_scorecard.md`](../notes/verification_scorecard.md): did your Skill, a sub-agent, and the whole set-up catch a known mistake?

## E. Capstone (15:50–16:15)

On a non-confidential piece of your own work (or the Card–Krueger panel if all your data are restricted), produce:

- one `AGENTS.md` rule;
- one Skill;
- one goal with 3 acceptance criteria;
- the output of a check command that ran.

Score with [`docs/capstone_rubric.md`](../docs/capstone_rubric.md). Then start [`docs/adoption_plan_7d.md`](../docs/adoption_plan_7d.md).
