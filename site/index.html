Agentic Coding for Economists

EIEF / Luiss, 26-27 November 2026 (Rome). Antonio Mele.

What this is

An eight-hour faculty workshop: fourteen ideas for supervising an AI agent the way you supervise a research assistant. One example all day, the synthetic Card-Krueger panel in examples/card-krueger-toy/. Those numbers are hand-written teaching data, not the 1994 survey, and they support no research claim.

Fork

Fork the original repository. Then clone your fork into a folder you choose. Do not clone meleantonio/ac4e-eief-workshop, and do not push to it. Only Antonio Mele can push to the original. If an agent does this for you, it must ask which folder to use before it clones, and it must clone your fork.

Fork ac4e-eief-workshop

git clone https://github.com/YOUR_GITHUB_NAME/ac4e-eief-workshop.git
cd ac4e-eief-workshop

Replace YOUR_GITHUB_NAME with your GitHub username. To send a change back, open a pull request from your fork.
